# EyeStudio Equipment Tracker

Scan shoot gear out before a shoot and check it back before you leave.

* The phone app is this folder, served by GitHub Pages.
* The data lives in the Google Sheet "Equipment Tracker App (data)" in the Equipment Tracker Drive folder.
* `apps-script/` holds the Google Apps Script that connects the two. Nothing secret is stored in this repository.

Only eyestudio.ae people on the People tab of the sheet can sign in.
